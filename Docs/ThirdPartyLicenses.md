# Third-party assets & licences (AC-17)

Last updated: 2026-11-23 (Milestone 5).

## Shipped in the game

| Asset | Source | Licence |
|---|---|---|
| Outfielder sprites, ball, stadium, crowd, flags, title art, UI kit, rank badges | Original. Drawn from code by `Tools/ArtGen/generate_m3_art.py` | Owned by the project; assigned to the client under the contract |
| "Say Hey Pixel" bitmap typeface (Regular + Bold) | Original. Same script (`GLYPHS` table) | Owned by the project |
| Sound effects, crowd beds, jingles, title music loop | Original. Synthesised by `Tools/AudioGen/generate_audio.py` (oscillators + seeded noise; the melody is an original composition) | Owned by the project |
| Fastball Fuel Coffee Co. logo (splash screen, icon, web loading screen, favicon) — `Art/Branding/FastballFuel_Logo.png` and files generated from it | Client's own artwork, supplied by the client on 2026-11-23 for use in this game | Client-owned trademark / artwork; used with the client's permission |
| Unity packages: URP 17.3, Input System 1.18, uGUI 2.0, 2D Sprite | Unity Technologies | Unity Companion License (no attribution needed in the game) |

No third-party fonts, sound libraries, sprite packs or music are used. The Milestone 1 plan listed Press Start 2P / Pixelify Sans (SIL OFL) as candidates; we did not use them because the GDD asks for "original retro arcade typography", and an original font needs no licence file.

## Names, likenesses and marks

The game shows no team logos, uniform numbers or archival imagery. Player and ballpark names appear only as text from `Data/Content/MissionContent.asset` and still need the client's licensing decision (Docs/01, Q1). The scoreboard reads VIS / HOME rather than team names.
