For whoever takes over the Unity project: how to get it, open it, change it, build it and publish it.

## 1. Set up a computer

### 1.1 Install
1. **Unity Hub** — <https://unity.com/download>.
2. In Unity Hub → *Installs* → *Install Editor* → *Archive* → **6000.3.9f1**, with the module **Web Build Support**. (Another 6000.3.x patch usually works; a different minor version will ask to upgrade the project — don't, unless you mean to.)
3. **Git** (<https://git-scm.com>) or **GitHub Desktop** (<https://desktop.github.com>).
4. *Optional:* **Python 3** (3.10+). Only needed for the art / sound generators, the local test server and the release zip tool. None of them use third-party packages.

### 1.2 Clone
```powershell
git clone https://github.com/AbdullahS17053/SayHeyDash.git
```
GitHub Desktop: *File ▸ Clone repository ▸ URL* → paste the address → *Clone*.
The repository is private: sign in with the GitHub account that was given access.

### 1.3 Open
1. Unity Hub → *Projects* → *Add* ▸ *Add project from disk* → pick the **SayHeyDash** folder (the one that contains `Assets/` and `ProjectSettings/`).
2. Check the editor version column says **6000.3.9f1**, then open it.
3. The first open takes several minutes: Unity rebuilds the `Library/` folder (it is not in Git).
4. Open **`Assets/_Project/Scenes/Main.unity`** and press **Play**.

> If the scene is missing or looks broken: **Say Hey Dash ▸ Build Main Scene**. It regenerates the scene from code and never overwrites the data assets (your tuning and text are kept).

## 2. Find your way around

```
Assets/_Project/
  Art/Branding/      client logo (source + generated icon / transparent logo)      ← M5
  Art/Sprites/       all game art (generated by Tools/ArtGen)
  Art/Fonts/         "Say Hey Pixel" bitmap font
  Audio/             sound effects + music (generated by Tools/AudioGen)
  Data/              ScriptableObjects you edit instead of code:
                       Tuning/  GameplayTuning, Difficulty_Default, Difficulty_Assisted
                       Scoring/ ScoringConfig
                       Content/ MissionContent (every on-screen word)
                       Audio/   AudioCueLibrary (sound per event + volume)
                       Visuals/ OutfielderAnimations
  Input/             SayHeyDashControls.inputactions (keyboard, gamepad, touch)
  Scenes/Main.unity  the game (one scene)
  Scripts/Runtime/   game code        Scripts/Editor/  build, import, scene, branding, tour tools
  Tests/             EditMode + PlayMode tests
Assets/WebGLTemplates/SayHeyDash/   the web page around the game (loader, click-to-play, rotate screen)
Tools/               ArtGen, AudioGen, WebTest server, WixHarness, Release zip, Tutorial video
Docs/                milestone reports, this guide, the user manual
Builds/              build output (not in Git)
```

The game is a single scene driven by a state machine (`Flow/GameFlowController`): Title → Mission briefing → Track ball → Catch → Catch sequence → Throw → Complete / Try again → Replay. Architecture details: [01_Scope_and_Architecture.md](01_Scope_and_Architecture.md).

## 3. Change the game in the Unity Editor (no code)

Select an asset in the **Project** window; its values appear in the **Inspector** (right). Edit, then press Play. Changes are saved with the project (*File ▸ Save Project* to be sure, then commit).

| I want to… | Asset → field |
|---|---|
| Give the player more / less time to reach the ball | `Data/Tuning/GameplayTuning` → `ballFlightDuration` (3.6 s) |
| Make the outfielder faster | `GameplayTuning` → `playerRunSpeed` (3.4), `playerAcceleration` (24) |
| Make positioning easier | `GameplayTuning` → `landingZoneRadius` (1.0 = 16 px; the ring scales with it) |
| Make the catch timing easier | `GameplayTuning` → `catchWindowSeconds` (0.4 s total) |
| Make the throw easier | `GameplayTuning` → `throwMeterSpeed`, `throwTargetZoneWidth`, `throwTimeLimitSeconds` |
| Tune Assisted mode | `Data/Tuning/Difficulty_Assisted` (multipliers) |
| Change score maxima / rank thresholds | `Data/Scoring/ScoringConfig` |
| Change any on-screen text (titles, buttons, hints, history replay, credits) | `Data/Content/MissionContent` |
| Turn on the museum / STORY MODE button | `MissionContent` → `museumUrl` |
| Re-balance sound | `Data/Audio/AudioCueLibrary` → volume per cue |
| Keep settings between Play sessions in the Editor | scene object **Settings** → *Persist In Editor* |

Tests guard the content: if a text no longer fits its box or a cue has no clip, the EditMode tests fail and say which one. More detail: [05 §3](05_M2_Gameplay_Prototype.md#3-tuning-guide-no-code-changes-needed), [06](06_M3_Visual_Production.md), [07 §3](07_M4_Content_and_Polish.md#3-editing-guide-no-code-changes-needed).

### 3.1 Logo, icon and splash screen (Milestone 5)
- The client logo is **`Assets/_Project/Art/Branding/FastballFuel_Logo.png`** (the file the client supplied; never edited by tools).
- To change it: overwrite that PNG (same name; black or transparent background; ideally ≥ 1500 px wide), then **Say Hey Dash ▸ Branding ▸ Rebuild Logo Files + Apply**. This regenerates:
  - `FastballFuel_Logo_Alpha.png` — trimmed, transparent; used by the splash screen,
  - `FastballFuel_Icon.png` — 1024 × 1024 icon (logo on black),
  - `WebGLTemplates/SayHeyDash/TemplateData/favicon.png`, `apple-touch-icon.png`, `logo.png` — browser tab icon, phone home-screen icon, loading-screen logo,

  and applies **Player Settings**: company / product name, default icon, splash screen (logo on black for 2.5 s, no Unity logo).
- See the result in *Edit ▸ Project Settings ▸ Player* (*Icon* and *Splash Image* sections).
- Every WebGL build re-applies these Player Settings, so they cannot drift.
- On the web, the logo splash plays right **after** the player clicks "CLICK OR TAP TO PLAY" (a start-up splash would play hidden behind that screen). The game draws it itself (scene object **BrandSplash**: fade-in / hold / fade-out times and zoom are in its Inspector; the logo image is its *Logo* child). It uses the same transparent logo, so *Rebuild Logo Files + Apply* updates it too — then run **Build Main Scene** only if you renamed the logo file.

### 3.2 Art and sound
All art and sound are generated by scripts, so colours and poses stay consistent:
```powershell
py -I Tools/ArtGen/generate_m3_art.py
```
```powershell
py -I Tools/AudioGen/generate_audio.py
```
Then **Say Hey Dash ▸ Build Main Scene**. To use hand-made art instead, replace the PNG with the same name and size in `Art/Sprites/...` (import settings are kept).

## 4. Build for the web

1. **Say Hey Dash ▸ Build ▸ WebGL (Release)** (about 10 minutes). Output: `Builds/WebGL/`.
2. Package for upload:
   ```powershell
   py -I Tools/Release/zip_webgl.py Builds/WebGL Builds/SayHeyDash_WebGL.zip
   ```
   Do **not** zip with Windows' *Send to ▸ Compressed folder* or `Compress-Archive`: they write backslash paths and itch.io then fails with "Could not load the game files".

Command line (Unity closed):
```powershell
& "D:\Gaming\6000.3.9f1\Editor\Unity.exe" -batchmode -quit -projectPath . -buildTarget WebGL -executeMethod SayHeyDash.EditorTools.Build.WebGLBuildPipeline.BuildFromCommandLine -logFile Logs/webgl_build.log
```
(Adjust the Unity path to your install, e.g. `C:\Program Files\Unity\Hub\Editor\6000.3.9f1\Editor\Unity.exe`.)

Player settings for WebGL are applied in code by `Editor/Build/WebGLBuildPipeline.cs` (Brotli + decompression fallback, size-optimised IL2CPP, the custom template, branding) so they are reviewable in Git.

### 4.1 Test the build locally
```powershell
py -I Tools/WebTest/serve.py Builds/WebGL 8601
```
Open <http://localhost:8601/>. Opening `index.html` straight from disk does not work (browsers block WebGL builds on `file://`).
Simulated Wix page (embeds the game cross-origin):
```powershell
py -I Tools/WebTest/serve.py Tools/WixHarness 8602
```
then open <http://localhost:8602/>.

### 4.2 Publish
- **itch.io (review builds):** upload the zip, *Kind of project: HTML*, tick *This file will be played in the browser*, viewport 960 × 540.
- **Production:** any HTTPS static host (Netlify, Cloudflare Pages, GitHub Pages, …). Upload the *contents* of `Builds/WebGL/`. No special headers are required (the decompression fallback handles hosts that don't send `Content-Encoding: br`).
- **Wix:** Wix can't host the game files; it embeds the hosted page. Wix Editor → *Add ▸ Embed Code ▸ Embed a Site* → paste the game URL → size the element 16:9 (e.g. 960 × 540). Full steps and limits: [User_Manual.md §7](User_Manual.md#7-for-the-website-owner-hosting-and-embedding) and [04](04_WebGL_and_Wix_Feasibility.md).

## 5. Tests

*Window ▸ General ▸ Test Runner* → **EditMode** → *Run All*, then **PlayMode** → *Run All*. Run both before every release build. `ScreenGalleryCapture` is marked *Explicit*: run it on its own to refresh the screenshots in `Docs/img/m4_screens/`.

Command line (Unity closed):
```powershell
& "D:\Gaming\6000.3.9f1\Editor\Unity.exe" -batchmode -projectPath . -runTests -testPlatform EditMode -testResults Logs/editmode.xml
```
```powershell
& "D:\Gaming\6000.3.9f1\Editor\Unity.exe" -batchmode -projectPath . -runTests -testPlatform PlayMode -testResults Logs/playmode.xml
```

## 7. Troubleshooting

| Problem | Fix |
|---|---|
| Hub says the editor version is missing | Install 6000.3.9f1 from the Hub's *Archive* tab (with Web Build Support) |
| Pink / missing materials, errors on first open | Wait for the import to finish; then *Assets ▸ Reimport All* only if errors persist |
| Main scene missing or broken | **Say Hey Dash ▸ Build Main Scene** |
| PoC scene became the only build scene | Same: **Build Main Scene** (do not run *Rebuild M1 Tech PoC Scene*) |
| WebGL option greyed out | Install the *Web Build Support* module for 6000.3.9f1 in the Hub |
| itch.io page shows "Could not load the game files" | Re-zip with `Tools/Release/zip_webgl.py` |
| Game page is blank from a local folder | Serve it (`Tools/WebTest/serve.py`), don't double-click `index.html` |
| Two "shader not supported" lines in the browser console | Known and harmless (URP on WebGL) |
| Settings don't stay after reload when embedded | Browser blocks storage in third-party iframes; the Settings menu says so. Works on the standalone page |
| Icon / splash still old after replacing the logo | **Say Hey Dash ▸ Branding ▸ Rebuild Logo Files + Apply**, then rebuild |

## 8. Handover tools (Milestone 5)

| Tool | What it does |
|---|---|
| *Say Hey Dash ▸ Handover ▸ Play Editor Tour* | Walks through the project in the Editor with captions (opens the scene, plays one mission, shows the data assets, branding, Player Settings, Build Profiles and Test Runner). Restores the one value it changes. *Stop Editor Tour* cancels it |
| `Tools/Tutorial/make_tutorial.ps1` | Re-records the tutorial video: title cards + a screen recording of the Editor tour + captions + narration (Windows voice), encoded by Unity's own `MediaEncoder` → `Builds/SayHeyDash_Tutorial.mp4`. Edit the words in `Tools/Tutorial/tutorial_script.txt` and `cards.txt`. Run with Unity closed and don't touch the mouse while it records: `powershell -ExecutionPolicy Bypass -File Tools/Tutorial/make_tutorial.ps1` |
| *Say Hey Dash ▸ Branding ▸ …* | Logo files and Player Settings (§3.1) |
