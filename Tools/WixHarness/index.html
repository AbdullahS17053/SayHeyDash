Arcade Mode

Manual checklist

  1. Game loads, loading bar shows, then "CLICK OR TAP TO PLAY" gate appears.
  2. Click the gate → arrows / WASD move the outfielder; Space blips. Host page does not scroll.
  3. Click outside the iframe → "click game to resume" hint appears; click the game → control returns.
  4. Diagnostics panel shows IFRAME YES, sensible FPS, no console errors.
  5. FULLSCREEN works only with allow="fullscreen"; OPEN LINK only with allow-popups.
  6. Each size preset: canvas letterboxes to 16:9, UI never cropped.
